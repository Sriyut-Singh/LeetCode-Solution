## 🧩 Problem-Solving Approach

For each contest, I try to follow this process:

1. **Understand** the problem and constraints.
2. **Think** about possible approaches.
3. **Implement** the solution.
4. **Test** it against different edge cases.
5. **Optimize** time and space complexity.
6. **Review** better solutions after the contest.

The goal is not only to get an **Accepted (AC)** submission, but also to understand *why* the solution works.
